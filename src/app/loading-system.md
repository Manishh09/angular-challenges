## Design a Loading System in Angular


### Requirements:

1. Should handle loading globally
2. Should handle loading for specific APIs as well
3. Should use Angular Material
4. Should verify in a sample component
   

### Steps:

1. Create a `Loading Service`
2. Create an `Interceptor` to handle the loading globally 
3. Create a `Loading Component` to handle UI for Loader
4. Use Angular Material's `Spinner` Or `ProgressBar` Component for displaying Spinner
5. Can use Custom Loader UI (Optional)
6. Create A Sample Component and Fetch Data using Dummy API
